# ios/App — the iPhone app

The X6 app from `plans/ios-mvp.md`: a small Swift shell around the shared
Compose Multiplatform UI in `android/ui`, with nothing leaving the phone.

## Layout

```
ios/App/
  SsaAssistant.xcodeproj/     generated by ios/tools/gen-xcodeproj.py (committed)
  SsaAssistant/               the Swift shell and the adapters
  SsaAssistantTests/          unit tests (real writer, reader, crypto, file store)
  SsaAssistantUITests/        the typed interview and the accessibility audit
  SsaResources.SHA256SUMS     pins for schema.json and the two goldens
```

## Building

The Kotlin framework must be rebuilt when `android/core`, `android/models` or
`android/ui` change:

```sh
# from android/
./gradlew :ui:assembleSsaCoreDebugXCFramework
```

It writes `ios/CoreCrypto/debug/SsaCore.xcframework`, which both the
`CoreCrypto` Swift package and this project link.

```sh
# from ios/App/
xcodebuild test -project SsaAssistant.xcodeproj -scheme SsaAssistant \
  -destination 'platform=iOS Simulator,name=iPhone 18 Pro'
```

No signing team is written into the project. To run on a phone, pass it:

```sh
xcodebuild test -project SsaAssistant.xcodeproj -scheme SsaAssistant \
  -destination 'platform=iOS,id=<UDID>' -allowProvisioningUpdates \
  DEVELOPMENT_TEAM=<team id>
```

## Resources in the bundle (Phase C4)

A build phase ("Stage pinned resources") copies these into
`SsaAssistant.app/SsaResources/` at build time, from the repository, so no
duplicate is committed and `models/whisper-base.en` (76 MB, git-ignored, fetched
by `tools/fetch-model.mjs`) stays where it is:

```
SsaResources/
  schema.json                     <- tools/schema.json
  golden/metrics.json             <- android/core/src/commonMain/resources/golden/
  golden/templateManifest.json
  forms/ssa-adult-disability-starter-kit-64-110.pdf
  forms/maine-developmental-services-intake-2025-06-18.pdf
  forms/SHA256SUMS                <- android/pdf/forms.SHA256SUMS
  vendor/pdf-lib.min.js
  vendor/ssa-pdf-writer.js
  vendor/SHA256SUMS               <- vendor/SHA256SUMS
  models/whisper-base.en/...      <- models/whisper-base.en/
  models/whisper-base.en/SHA256SUMS
  SsaResources.SHA256SUMS
```

`Resources` (AppServices.swift) checks every group against its pins the first
time a file in it is needed, and refuses a file that does not match. The model
is checked the first time the transcriber is built, not at launch.

`core`'s `readResource` reads from the main bundle's resource root, so
`ShellApp` points `IosResources.roots` at this folder before the schema loads.

## Re-pinning

After a deliberate change to `tools/schema.json` or a regenerated golden:

```sh
# from the repository root
shasum -a 256 tools/schema.json \
  android/core/src/commonMain/resources/golden/metrics.json \
  android/core/src/commonMain/resources/golden/templateManifest.json
```

and write the three lines into `SsaResources.SHA256SUMS`.
