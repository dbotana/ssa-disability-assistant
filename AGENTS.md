# AGENTS.md

Rules for coding agents working in this repository (opencode, Claude Code, agent-loop stages).
Read this before running any command.

## What this repository is

A voice assistant that helps a blind user fill out disability forms (SSA-64-110 and Maine DHHS
Developmental Services Intake) without anything they say leaving the device. The web app in
`src/` is the reference implementation. `android/` and `ios/` port it, and the port must match
the reference exactly where `ios-android-mirror-plan.md` says so (its "Parity contract").

```
src/                     web app, the JS reference implementation
tests/                   node tests for the web app (node tests/<file>.js)
tools/                   schema export, golden generation and checks, turn scenarios, eval tools
tools/golden/            goldens are generated from the JS reference; check.mjs checks they're fresh
android/                 Gradle project: core and models (Kotlin multiplatform), ui (Compose Multiplatform), pdf, speech, core-device, app, ...
ios/CoreCrypto/          Swift package (product SsaKit): the iOS Crypto and SsaPdf, linked against the SsaCore XCFramework that :ui builds
ios/App/                 the iOS app; SsaAssistant.xcodeproj is generated by ios/tools/gen-xcodeproj.pyforms/                   blank official PDF templates
models/, vendor/         pinned model and library files, checked by tests/vendor-integrity.js
ios-android-mirror-plan.md   the plan for the iOS and Android apps, with a Progress log
TODO.md                  open work and decisions later readers need
agent-loop-runs/         agent-loop run records (git-ignored, not recoverable if lost)
plans/                   working plans (git-ignored)
```

## Git: never run these

Untracked and git-ignored files are not recoverable, and this repo has many of them:
`agent-loop-runs/`, `plans/`, `assignment-info/`, `.claude/settings.local.json`, build outputs
and in-progress work. One command can delete all of them.

**Never run:**

- `git stash` in any form (`push`, `-u`, `-a`, `--all`, `--include-untracked`, `--keep-index`),
  or `git stash pop`/`apply`/`drop`/`clear`;
- `git clean`, with any flags;
- `git checkout -- <path>`, `git checkout .`, or `git restore` on a working-tree path;
- `git reset`, in any mode (`--hard`, `--mixed`, `--soft`, or with paths);
- `git rebase`, `git commit --amend`, `git push --force`, `git branch -D`, `git worktree remove`;
- `rm -rf` on any folder you did not create in this session.

**Allowed:** `git status`, `git diff`, `git log`, `git show`, `git ls-files`, `git blame`, and
`git show <rev>:<path>` to read an old version of a file.

**To undo your own change,** edit the file back by hand, or read the old version with
`git show HEAD:<path>` and write it out. Never use git to throw away work. If you think a file
has been lost or changed by mistake, stop and report it. Don't try to recover it.

**Don't commit or push** unless the task asks for it. The owner commits between runs.

## Files

- Don't move files out of the repo (for example to `/tmp`) to make a build pass. If a file
  doesn't compile, fix it, or leave it and report the error.
- Ask before deleting, moving or overwriting a file you did not create in this session.
- Never edit anything in `agent-loop-runs/` or the plans agent-loop saves. They are records.
- Never commit a filled form, an exported session, or anything else that could hold a real SSN
  (see `.gitignore`). Use the synthetic fixtures in `tests/fixtures/`.

## Goldens and the port

- The JS in `src/` is the reference. When behaviour changes, change the JS first, regenerate the
  goldens from it, then update the Kotlin port.
- Fix the port, never the goldens. A golden may change only when the JS reference produces the
  change. Never edit a golden by hand.
- Goldens are generated in UTC. Run Gradle tests with `TZ=UTC`.
- `check.mjs` compares against HEAD: after a golden is regenerated it fails until the owner commits.
  Regenerate with `TZ=UTC node tools/golden/index.mjs` then `node tools/export-schema.mjs`, run twice,
  and report the diff instead.
- When tools/schema.json or the two main goldens (metrics.json, templateManifest.json) change, re-pin ios/App/SsaResources.SHA256SUMS as ios/App/README.md says, or tests/vendor-integrity.js fails.

## Running commands

The Claude stages run in a command sandbox. Gradle, adb, the emulator, simctl and xcodebuild
work only when the command matches an allowed pattern. So:

- Run each Gradle, adb, emulator, xcrun, xcodebuild and swift command on its own, never chained
  with `;`, `&&` or `|`, from the directory the plan gives (usually `android/` or
  `ios/CoreCrypto/`).
- If a command is refused, record the exact refusal word for word and carry on. Don't work
  around it with another tool.
- Don't change Kotlin, Gradle, AGP or library versions unless the task says to. If an upgrade is
  needed, upgrade only that and what depends on it.
- The iOS app lives only in ios/App/. Its .xcodeproj is generated: change ios/tools/gen-xcodeproj.py, rerun it, and check with `python3 ios/tools/gen-xcodeproj.py --check`. Never hand-edit the .xcodeproj.

Common checks. Each line runs on its own, from the directory in the comment above it.

```sh
# ---- web, from the repository root -----------------------------------------
for f in tests/*.js; do node "$f"; done          # web tests; tests/ios-audit.js audits whatever iOS builds exist
node tools/smoke.mjs                             # turn-loop smoke test
DEVELOPER_DIR=/Library/Developer/CommandLineTools node tools/golden/check.mjs   # goldens fresh; compares against HEAD
# after a JS change that moves a golden: regenerate twice and compare (check.mjs fails until the owner commits)
TZ=UTC node tools/golden/index.mjs
node tools/export-schema.mjs
# when tools/schema.json, metrics.json or templateManifest.json change, re-pin ios/App/SsaResources.SHA256SUMS
shasum -a 256 tools/schema.json android/core/src/commonMain/resources/golden/metrics.json android/core/src/commonMain/resources/golden/templateManifest.json

# ---- pinned runtime and models, from the repository root ------------------
node tools/fetch-onnxruntime.mjs --verify
node tools/fetch-model.mjs --verify
node tools/golden/models.mjs --check

# ---- core, from android/ ----------------------------------------------------
TZ=UTC ./gradlew :core:jvmTest
TZ=UTC ./gradlew :core:compileCommonMainKotlinMetadata
SIMCTL_CHILD_GOLDEN_DIR=$PWD/core/build/ios-test-resources ./gradlew :core:iosSimulatorArm64Test

# ---- Android app and audits, from android/ (ANDROID_HOME=~/Library/Android/sdk) --
./gradlew verifyOnnxRuntimeJava
TZ=UTC ./gradlew :app:assembleDebug
./tools/audit-permissions.sh app/build/outputs/apk/debug/app-debug.apk $(find app/build/intermediates/merged_manifest -name AndroidManifest.xml)   # an .aab also needs BUNDLETOOL=<bundletool-all jar>
./tools/audit-native.sh app/build/outputs/apk/debug/app-debug.apk

# ---- Android devices, from android/; needs the ssa35 emulator booted --------
TZ=UTC ./gradlew :core-device:connectedDebugAndroidTest
./tools/run-pdf-spike.sh ssa35
TZ=UTC ./gradlew :speech:connectedDebugAndroidTest          # Whisper; the MMS form is below

# ---- models: Whisper and MMS (spike 3b) -------------------------------------
# MMS needs android/models/third_party/mms-1b-all/ (about 27 GB, git-ignored).
# Run one model process at a time: an fp32 graph is 3.86 GB.
# from the repository root
node tools/fetch-model.mjs --verify mms
android/models/third_party/mms-1b-all/.venv/bin/python tools/golden/mms.py --check   # owner's Mac only
# from android/ (on the JVM, MMS_DIR defaults to models/third_party/mms-1b-all)
TZ=UTC ./gradlew :models:jvmTest
SIMCTL_CHILD_GOLDEN_DIR=$PWD/models/build/ios-test-resources SIMCTL_CHILD_MODEL_DIR=$PWD/../models/whisper-base.en SIMCTL_CHILD_MMS_DIR=$PWD/models/third_party/mms-1b-all SIMCTL_CHILD_MMS_GRAPH=fp32 ./gradlew :models:iosSimulatorArm64Test   # then MMS_GRAPH=q8
# ssa35 runs q8 (4 GB RAM). First push, for each graph folder (onnx-lin, ..., lid-126), its SHA256SUMS,
# config.json, preprocessor_config.json, q8/model_quantized.onnx and, for ASR, tokenizer_config.json and
# vocab.json to /data/local/tmp/mms/<folder>/ (chmod 755); /data holds only two q8 graphs at once.
TZ=UTC ./gradlew :speech:connectedDebugAndroidTest -Pandroid.testInstrumentationRunnerArguments.MMS_DIR=/data/local/tmp/mms -Pandroid.testInstrumentationRunnerArguments.MMS_GRAPHS=lin,lid

# ---- iOS ---------------------------------------------------------------------
# from android/: rebuild the framework whenever android/core, models or ui change
./gradlew :ui:assembleSsaCoreDebugXCFramework
# from ios/CoreCrypto/
xcodebuild test -scheme CoreCrypto-Package -destination 'platform=iOS Simulator,name=iPhone 18 Pro' -derivedDataPath .build/xcode
# from the repository root: the generated project is current
python3 ios/tools/gen-xcodeproj.py --check
# from ios/App/: the app (-derivedDataPath build is where tests/ios-audit.js looks for the .app)
xcodebuild test -project SsaAssistant.xcodeproj -scheme SsaAssistant -destination 'platform=iOS Simulator,name=iPhone 18 Pro' -derivedDataPath build
# from the repository root: the ONNX Runtime binary audit
ios/tools/audit-binary.sh android/models/build/onnxruntime-ios/onnxruntime.xcframework
```

## Privacy

- Nothing the user says or types may leave the device. Don't add network calls, analytics,
  crash reporting, cloud speech or translation services, or dependencies that bring them in.
  `tests/no-network.js`, the Android permission audit and the iOS binary audit enforce this.
- Models run locally. New model or library files must be pinned and listed in the checksums.
- Don't add dependencies unless the plan calls for them.

## Reporting

- Record what you ran and what happened, with exact commands and results, in the plan's
  Progress section and in `TODO.md` when the task asks.
- Say plainly what you could not run or verify. Don't claim a check passed unless you ran it and
  saw it pass.
- Never invent dates, numbers, test counts or results.
